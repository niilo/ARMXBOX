# ARMXBOX privacy

ARMXBOX runs the emulator and stores its settings, imported files, game library and saves on your device. It does not require an ARMXBOX account.

The game library can download cover art from the community cover repository hosted on GitHub. Network requests expose normal connection information (such as your IP address) to the hosting service. Links in the app open external websites in your browser. Xbox networking features can connect to services that you configure.

Debug logging is optional. Exported logs can include device information, performance measurements, game names and file paths. Review logs before sharing them. A startup entry identifies the installed app version and build variant for troubleshooting.

ARMXBOX is based on X1 BOX, xemu and QEMU. This document describes this fork; third-party websites and services have their own privacy policies.
