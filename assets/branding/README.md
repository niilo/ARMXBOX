# ARMXBOX icons

Original ARMXBOX artwork generated for this project: an angular A and processor mark. Release uses lime/teal; Dev uses violet/amber and a DEV badge. These do not use the Xbox or Microsoft logo.

The two PNG masters are the source for Android launcher/store assets, desktop PNG/ICO assets and embedded native UI images. Android monochrome resources provide a small themed A silhouette. Preserve the adaptive foreground inset when updating assets.
