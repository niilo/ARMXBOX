# ARMXBOX icons

The selected production artwork uses a green Xbox-style sphere/X and ARMXBOX wordmark. Debug/Profile use the matching red design with a DEV badge. These replace the earlier A-and-chip designs in v1.2.14.

The two PNG masters are the source for Android launcher/store assets, desktop PNG/ICO assets and embedded native UI images. Run `scripts/package-branding-icons.sh` from a machine with ImageMagick to regenerate all packaged sizes and native payloads. Android monochrome resources provide clean X silhouettes, with a separate Dev marker. Preserve the adaptive foreground inset when updating assets.

The artwork incorporates the Xbox logo selected for this project. Xbox and Microsoft names and logos belong to Microsoft. ARMXBOX is an independent emulator project.
