# v1.2.12 — tested Pocket S RC15 baseline

This release merges the tested RC15 CPU performance work on top of v1.2.11. It keeps the rendering and audio behavior that looked and sounded normal in both production-app comparison runs.

The x87 policy initialization is moved out of frequently called arithmetic helpers. In the final ARM64 binary, representative wrapper stack frames shrink from 208 to 80 bytes and the square-root frame from 176 to 64 bytes. Arithmetic admission checks, precision, exception handling and reference fallbacks remain unchanged. The tested configuration keeps guarded PC24 arithmetic enabled, with transfer optimization, raw x87 stack optimization and CPU profiling disabled.

In the matched first 190 seconds of the supplied SSX 3 / Pocket S / Turnip / 3× logs, RC15 averaged 36.26 FPS versus Control's 34.22 FPS (about 6% higher). The earlier 75-second window showed about 13% improvement. These are single device runs rather than a controlled benchmark: temperatures and throttling differed, and guest workload was not replayed frame for frame. Sustained 60 FPS has not been reached.

Validation includes full cross-platform CI, numerical/state regression checks for the CPU changes, final ARM64 binary inspection and Android production-signature checks. Device feedback reported normal visuals, sound and input for both comparison builds.

Next performance work should profile the remaining CPU helper/translation costs and GPU submission time with clearly identified APKs and comparable runs. Preserve the RC8+ rendering correctness fixes; avoid speculative cache invalidation shortcuts. ARMXBOX branding and visible build identities follow as a separate housekeeping release.
