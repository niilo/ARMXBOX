# X1 BOX v1.2.11 — Pocket S performance baseline

This release brings the Pocket S optimization work to master, including guarded
native ARM64 x87 arithmetic, Vulkan rendering corrections, reduced renderer
setup/copy work and voice-mixing improvements. Android versionCode is 40.

## Download and install

Download **x1box-android-release-linux.apk** from this release's assets for
Android ARM64 devices. It is a signed production Release APK, not a debug build.
The macOS-built Release APK is an alternative build of the same source. The AAB
files are for distribution tooling; use an APK for installation on your device.
Android 10 or newer and Vulkan are required.

The production application is **X1 BOX** (`com.izzy2lost.x1box`). It installs
separately from the **X1 BOX Test** RC builds (`com.izzy2lost.x1box.dev`), whose
settings and private files are separate. Existing production installations can
update when signed with this fork's release key; upstream or differently signed
installations require a separate migration. Firmware and games remain user-supplied.

## Selected improvements

- Guarded PC24 add/subtract/multiply/divide/square root uses ARM64 hardware for
  eligible operands. Full 80-bit x87 registers, guest rounding/exception state
  and the existing softfloat fallback are preserved.
- Rendering work fixes stale uniforms, texture/descriptor notifications and
  surface/vertex freshness, and retains conservative synchronization. Renderer
  optimizations reduce repeated shader/dynamic-state work and CPU copies.
- Voice mixing reuses attenuation calculations. Audio backend, rate, buffer and
  worker telemetry helps future diagnosis without changing audio timing policy.
- Native arithmetic, TCG peephole optimization, TB cache hints and ThinLTO remain
  enabled with assertions. Experimental raw x87 stack lowering, streamlined
  transfers and CPU profiling default OFF. Saved profiling preferences do not
  enable hooks in the normal Release APK.

## Pocket S observations

SSX 3, 3x resolution, AYANEO Pocket S / Adreno 740, Turnip Mesa 26.3:

| Normal candidate | First 75 seconds of settled gameplay |
| --- | ---: |
| RC14 Control, PC24 OFF / transfer OFF | 25.57 FPS |
| RC14, PC24 ON / transfer OFF | **31.28 FPS** |
| RC14 Combined, PC24 ON / transfer ON | 30.74 FPS |

RC14 logged **22.3% higher FPS than the fresh control** in this pair. The gain
appeared in both early and later sections. Combined provided no clear additional
transfer benefit, so transfers remain OFF. Its longer run averaged 33.15 FPS
across about 3.5 minutes; that longer average is not directly comparable with
the shorter runs above.

These are individual runs with different temperatures and sampled workloads,
not a controlled comparison against the previous public release or a universal
22.3% claim. The Combined export omitted startup flags/settings. Reported current
thermal severity stayed 0, and no fresh crash, Vulkan failure or audio-error
signature appeared. Logs cannot verify pixel/audio quality. Sustained 60 FPS,
the other target games and Steam Deck performance are not established.

## Validation and known limits

Numerical/helper-state tests against unchanged real softfloat and immutable
reference helpers passed under GCC ASan/UBSan and Clang, including independent
reruns and semantic negative controls. ARM64 inspection of the packaged RC14
binaries verified the rounding/exception guards, native arithmetic and absence
of profiler hooks. The performance source commit also passed cross-platform CI.
The signed release builds and checksums identify the final release artifacts.

The InputEventSender warning stream remains a diagnostic lead with unmeasured
cost. Adaptive unlock still responds to workload; it has not been forced or
retuned. Different games, drivers and devices may behave differently.
